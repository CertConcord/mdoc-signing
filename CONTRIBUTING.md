# Contributions

Contributions must identify the technical problem, the current upstream revision, retained semantics, security implications and reproducible evidence. Existing standards and extensions are considered before additional objects or protocol states.

By contributing, contributors provide the applicable licenses identified in the README and must have authority to submit the material. DCO sign-off and a separate CLA are optional. No additional specification patent commitment is inferred from a contribution. Issues and pull requests are welcome. Unsubmitted proposal status changes only after an actual upstream submission.
